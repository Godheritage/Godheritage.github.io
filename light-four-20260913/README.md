# 四个 Light 实验 · 最终看板

打开本目录的本地服务地址（server-info.json）。网页采用原形三维模型和已有姿态；不运行仿真。

- 总览：正式结果、开发试算、实物零件/刚体、原始轮与两轮补时。
- 详情：播放/暂停、保存帧步进、时间拖动、末帧、速度、循环、线框、机架透明、近看、轨迹线、并排比较。
- 前缀默认不循环；停止在实际保存末点。平滑显示只作相邻显示帧间的插值。
- GLB由对应版本的原始STEP表面生成，每段回放绑定自己的几何。没有另造理想动画。
- 网页显示帧经过均匀索引抽取并保留端点；这是显示压缩，与Harness 10 Hz原形审计的采样不是一回事。
- metrics.json保留用时/结果依据；replay-data.json保留轨迹源、采样索引和几何对应核对。时间未知项为null。
- 三段控制器wall按已记录的started_at至finished_at求和，不包含停机间隔，也不补造未记录的进程启动前奏。本次外层进程wall另保留在源数据。
- 正式0/4；插销新协议的完整开发试算通过单列。STEP登记修复不追改正式实验成绩。

Token 的总量因记录不完整保留为空。tokens.json 仅保留可确定逐 turn 来源的已记录部分及缺口，不按数字递增猜测累计口径，不把缓存输入重复加总。
